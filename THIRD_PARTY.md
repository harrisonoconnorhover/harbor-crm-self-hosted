# Third-party notices

Harbor’s own code is licensed under MIT. The root and fixture lockfiles identify the exact public packages fetched when you build and run tests. Those packages retain their respective licenses.

The web server is built from Cloudflare’s MIT-licensed Vinext production entry. Vinext includes pathslash 0.1.0. Its [MIT notice](runtime/licenses/pathslash-MIT.txt) is copied alongside the built worker and server files. The build also emits license lists for bundled packages in its output. Installed packages and the base images supply their own notices.

Harbor and its sample workspace use original branding and fictional records. The source repository distributes no prebuilt container or database snapshots.
